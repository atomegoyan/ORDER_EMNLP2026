\caption{\textbf{ORDER at a glance.}
\textbf{Left (offline, document-conditioned).} From the three corpora
(\textit{Les Débats}, \textit{Le Gaulois}, \textit{L'Intransigeant}),
we discover semantic question clusters and learn, per cluster~$c$, a
pre-built index $I_c$ that pairs the best chunking strategy
$\text{chunking}_c^{\star}$ with the best metadata configuration
$\text{metadata}_c^{\star}$ (Sections~\ref{sec:indexing-methodology}
and~\ref{sec:metadata-methodology}).
\textbf{Right (online, query-conditioned).} At inference, a single
embedding $\mathbf{v}_q$ flips three switches: (1)~per-cluster
chunking and (2)~per-cluster metadata are selected by nearest-centroid
assignment over the cluster menu on the left; (3)~the active source
set $\mathcal{A}_q$ is predicted by a supervised query router (QRe,
Section~\ref{sec:classifier}), and the retrieval budget is split
evenly across the active sources via the uniform multi-source
allocator (UMS, Section~\ref{sec:retrieval-strategies}). Online
overhead is one embedding plus one nearest-centroid lookup. Gold
documents are marked $\star$.}
